# 暗記アプリ（外部開発用・単体版）

Muse 内で作った暗記アプリと同じ機能を、Muse の外でも開発・実行できるように
書き起こした単体コードベースです。バックエンドなしで動きます。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 型チェック + 本番ビルド (dist/ に出力)
npm run preview  # ビルド結果のプレビュー
```

Node.js 18 以上を推奨します。

## 機能

- **問題集（デッキ）**: 複数作成・編集・削除。問題集ごとに問題数と達成度%を表示
- **問題形式（4種類）**
  - 一問一答: 答えを表示して自己採点（覚えた／まだ不安）
  - 選択問題: 選択肢2〜6個、正解1つ、解説付き、自動判定
  - 複数選択: 選択肢2〜8個、正解は複数。すべて一致したときだけ正解
  - 穴埋め: 問題文の `___` が空欄。複数空欄可、自動判定
- **テキスト一括入力**: 1行に1問「問題|答え」形式で一問一答をまとめて追加
- **学習モード**
  - 解く問題数: すべて／5／10／20／30／任意の数
  - 出題順: 達成度が低い順／シャッフル／作成順／達成度が高い順
  - 出題範囲の絞り込み: 達成度レベル別、未学習のみ
  - 問題と答えの入れ替え（一問一答のみ）
  - 時間計測、読み上げ（Web Speech API、対応ブラウザのみ）
  - 結果画面（正解数・正解率・所要時間）と、間違えた問題だけの再出題
- **達成度（6段階）**: 未学習・苦手・要復習・理解中・ほぼ定着・定着（星表示付き）
  - 挑戦回数と正解率から判定（未学習=0回、苦手=正解率40%未満、要復習=60%未満、
    理解中=80%未満、ほぼ定着=80%以上、定着=正解率100%かつ5回以上）
  - 問題集ごとに段階別の内訳バー・件数と達成度%（レベル平均）を表示し、段階で絞り込み可能
  - 回答結果は問題ごとに記録され、達成度に反映される
- **AIで問題を作成**（要設定、下記）
  - 文章の貼り付け、画像（最大3枚）、テキストファイル（.txt/.md/.csv）から生成
  - **問題数はAIが判断**（素材の量と大事なポイントから決定、上限50問、水増しなし）
  - 形式は 一問一答／選択／複数選択／穴埋め／おまかせ、重点ポイントの指定も可
  - プレビューは**最初は全問選択**された状態で開き、不要な問題だけチェックを外して、
    選んだ問題だけを追加できる（プレビュー上で問題文・答え・解説の編集も可）

## データの保存

- すべてのデータ（問題集・問題・学習記録）はブラウザの **localStorage**
  （キー: `memorization-app:data:v1`）に保存されます。
- サーバーには送信されません。別のブラウザ・別の端末とは同期されません。
- ブラウザのデータを消すと消えるので、大事な問題集は一括入力用のテキスト等で
  手元に控えを残すことをおすすめします。

## AIプロバイダの設定と差し替え

AI生成は `src/ai/provider.ts` の1モジュールに隔離されています。
画面側は `generateQuestions()` と `isAiConfigured()` しか呼びません。

### 設定（OpenAI互換APIの場合）

`.env.example` を `.env` にコピーし、値を入れて開発サーバーを再起動してください。

```bash
VITE_AI_API_URL=https://api.openai.com/v1   # ベースURL。末尾が /chat/completions の完全なURLでも可
VITE_AI_API_KEY=sk-...
VITE_AI_MODEL=gpt-4o-mini                   # 使うモデル名
```

- 未設定の場合は、AIパネルに「AIが未設定です」と表示されるだけで、
  アプリの他の機能はそのまま使えます（クラッシュしません）。
- 注意: Vite の `VITE_` 変数はブラウザ側に埋め込まれます。APIキーは
  公開サイトにそのまま置かず、個人利用の範囲で使ってください。
  本格運用では、キーを隠す中継サーバーを用意し、そのURLを
  `VITE_AI_API_URL` に指定する構成を推奨します。

### 差し替え方法

- **別のモデル**（同じプロバイダ）: `.env` の `VITE_AI_MODEL` を変えるだけです。
- **別のプロバイダ（OpenAI互換）**: `.env` の URL・キー・モデルを変えるだけです。
- **互換でない形式のAPI**: `src/ai/provider.ts` の `generateQuestions()` 内の
  リクエスト組み立てとレスポンス解析だけを変更してください。
  返り値の型（`GenerateResult` / `GeneratedQuestion`）を守れば画面側は無変更です。

## 制限事項

- **PDFは直接読み込めません。** AI生成でも同様です。
  必要なページのスクリーンショットを画像として選んでください。
- 画像からの生成は、使うモデルが画像入力（Vision）に対応している必要があります。
- AI生成でアップロードした画像は、生成リクエスト時にプロバイダへ送信されます。
- 読み上げは Web Speech API を使うため、ブラウザによっては使えません。
- データは端末・ブラウザごとに分かれます（同期なし）。

## ディレクトリ構成

```
src/
  App.tsx               画面遷移（一覧/詳細/学習）と全体の状態管理
  types.ts              Deck / Card の型定義
  mastery.ts            達成度6段階の判定と集計
  storage.ts            localStorage の読み書き
  ai/provider.ts        AI生成プロバイダ（差し替えはここだけ）
  components/
    DeckDetail.tsx      問題集詳細（統計・問題一覧・追加導線）
    CardForm.tsx        問題の作成・編集フォーム（4形式）
    AiPanel.tsx         AI生成パネルとプレビュー（全選択→外して追加）
    Study.tsx           学習設定・学習画面・結果画面
```
